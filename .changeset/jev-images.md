`@askif/jev` can send PNG and JPEG images when `jev()` is called with `images: true`. Image input stays off unless that option is set, and a state that contains an image then fails with `UNSUPPORTED_INPUT` instead of being sent as text. A packed `decideMany` call numbers those images in one list.

The `@askif/clef` README records the current clef-flash list price ($0.038 per million input tokens) and the 24,576-token context of hosted clef-flash.
